## 👋 About me

I'm a **Test Automation Engineer with 7+ years of experience** in mobile and web automation, currently focused on **Android E2E testing with Kotlin and UI Automator**. I build stable, maintainable test frameworks that catch regressions early and let teams ship with confidence.

- 🤖 **Now:** Automating E2E flows for a large-scale enterprise Android app (Kotlin, UI Automator)
- 🎯 **Focus:** Android SDET — test architecture, flaky-test reduction, CI-integrated test pipelines
- 🌱 **Learning:** Playwright and Cypress
- 💬 **Ask me about:** Android test automation, TestNG and Cucumber (BDD) frameworks
- 📍 **Based in:** Ireland
